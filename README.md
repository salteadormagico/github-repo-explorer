GitHub Repo Explorer

A Python CLI application that allows users to explore GitHub profiles and their public repositories using the GitHub API.

Features
Search for GitHub users.
Display user information and public repository counts.
List public repositories and their star counts.
View repository details, including name, description, stars, and programming language.
Handle invalid inputs and API request errors.
Technologies
Python
Requests
GitHub REST API
Requirements
Python 3
The requests library
Installation
Clone this repository.

Install the required dependency:

pip install requests

Run the Python script:

python main.py

Replace main.py with the actual name of your Python file if necessary.

Usage
Enter a GitHub username.
View the user's public repositories.
Enter the number of a repository to see its details.
Type salir to stop searching or leave the repository selection.
Purpose

This project was created to practise Python programming, working with REST APIs, handling exceptions, validating user input, and organizing code into functions.
